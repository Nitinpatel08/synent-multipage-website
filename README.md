# Multi-Page Website

A responsive multi-page website built using HTML, CSS, and JavaScript.

## 📌 Project Overview

This project demonstrates a professional website structure with multiple pages and a consistent user interface. It includes navigation between pages and responsive design principles.

## 🚀 Features

- Responsive Design
- Multi-Page Navigation
- Home Page
- About Page
- Services Page
- Contact Page
- Clean and Simple UI
- Reusable CSS Styling
- JavaScript Support

## 📂 Project Structure

```
multipage/
│
├── index.html          # Home Page
├── about.html          # About Page
├── services.html       # Services Page
├── contact.html        # Contact Page
├── style.css           # Main Stylesheet
├── script.js           # JavaScript File
└── README.md           # Project Documentation
```

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📖 Pages

### Home Page
- Welcome section
- Website introduction

### About Page
- Information about the company/website

### Services Page
- List of services offered

### Contact Page
- Contact information and inquiry section

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Nitinpatel08/synent-multipage-website.git
```

2. Navigate to the project folder:

```bash
cd synent-multipage-website
```

3. Open `index.html` in your browser.
